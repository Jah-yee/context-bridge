# SUPPORT.md for context-bridge

## Getting Help

- **Bug Reports:** Open an issue with the `bug` label. Include your setup (embedding model, storage backend, Python version) and the operation that failed.
- **Feature Requests:** Open an issue with the `enhancement` label describing the integration or capability you need.
- **Performance Issues:** Open an issue with the `perf` label for latency or memory concerns.
- **Usage Questions:** Open an issue with the `question` label.
